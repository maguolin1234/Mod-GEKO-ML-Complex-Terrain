# Askervein Hill benchmark data

Included files:

- `askervein_elevation-roughness.map`
- `askervein_inlet1.txt`
- `askervein_sensor1.txt`
- `askervein_validation1.txt`

Official source cited in the manuscript:
https://doi.org/10.5281/zenodo.4095052

These files provide terrain/roughness, inlet information, sensor locations, and validation measurements used for the Askervein Hill field-scale benchmark.
